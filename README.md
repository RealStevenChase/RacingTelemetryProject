# RacingTelemetryProject
"Analyzed racing telemetry data using Python to clean, transform, and model large datasets. Applied machine learning (K-Means, regression, decision trees) to predict performance trends and built visual dashboards for insights, optimizing lap time analysis."

In this repo there are 2 ipynb files and 2 pdf presentations that go with them.
The ipynb files is my running code, where the pdfs are presentations that explain the results and my thinking.
